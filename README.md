# Personal Portfolio Website - Viraj Wakure

A responsive personal portfolio built with HTML, CSS and JavaScript as a project for Bosscoder School of Technology.

## Features
- Home with name, avatar, introduction and navigation buttons
- About, Education, Skills (animated progress bars), Projects (details popup), Hobbies, Achievements
- Contact section with LinkedIn and GitHub links, and a form validated with JavaScript
- Dark mode (default) and light mode toggle that remembers your choice
- Typing intro, animated particle background, scroll progress bar, back-to-top button
- Sticky navigation with smooth scrolling and active-section highlight
- Responsive layout for laptops, tablets and phones

## Project structure
```
index.html   - page structure and content
style.css    - styling, themes and responsive layout
script.js    - theme switch, navigation, typing effect, skill bars, popup, form validation
assets/      - images (profile.jpg, project1.jpg, cert1.jpg)
```

## How to run
Download or clone the repository and open `index.html` in any modern browser.
